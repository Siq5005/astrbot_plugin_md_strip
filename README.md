# astrbot_plugin_md_strip

发送前剥掉 QQ 不渲染的 Markdown 符号。

## 解决什么问题

模型经常把 `**加粗**`、`# 标题`、`` `代码` `` 直接写进回复，QQ 不渲染这些语法，
群里看到的就是一串星号和井号。

## 做了什么

挂在 `on_decorating_result` 上，扫描出站消息的 `Plain` 段：

- `**粗体**` / `__粗体__` → 去掉标记，保留文字
- `# 标题` → 去掉井号
- `` `行内代码` `` / 代码围栏 → 去掉反引号
- `> 引用` → 去掉箭头
- `- 列表` / `* 列表` → 换成 `· `

只动符号，不动内容和语气。

## 安装

把本仓库放进 AstrBot 的 `data/plugins/` 目录，重启 AstrBot。

## 兼容性

- AstrBot：`>=4.16,<5`
